# x500_nav3d

ROS 2 packages describing the PX4 X500 vehicle and configuring it for MoveIt.

## Packages

- `x500_nav3d`: metapackage that installs the complete X500 integration.
- `x500_description`: URDF/Xacro model, meshes, RViz configuration, and display launch file.
- `x500_moveit_config`: MoveIt configuration generated with the MoveIt Setup Assistant.
